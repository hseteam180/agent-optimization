## Проблема
LLM-агент может использовать локальный инструменты, веб-поиск, MCP, размышления и внешние инструменты для работы. При этом в его запусках возникают повторяющиеся ошибки: неверный выбор инструмента, некорректные аргументы, лишние вызовы, неверная интерпретация наблюдений и преждевременное завершение.

Ручное исправление инструкций требует времени и может ухудшить работу на других задачах. Необходимо исследовать, какая обратная связь позволяет автоматически улучшать конфигурацию агента, насколько улучшения переносятся на новые проблемы, задачи и каких затрат требует поиск.

## Цель и исследовательский вопрос

**Цель:** разработать и экспериментально оценить систему, которая анализирует завершённые запуски агента, выявляет повторяющиеся ошибки, предлагает изменения конфигурации и проверяет кандидатов на отдельном наборе задач.

**Исследовательский вопрос:** позволяет ли обратная связь, сформированная из проверяемых событий среды, эффективнее улучшать агента при ограниченном бюджете, чем свободный текстовый анализ его траекторий?
