# Сценарии отказов SREGym-Lite

## 1. Что такое SREGym

**SREGym (Site Reliability Engineering Gym)** - платформа для разработки и оценки ИИ-агентов, которые диагностируют и устраняют неисправности в работающей IT-инфраструктуре. В отличие от статического набора логов, SREGym воспроизводит инциденты в развёрнутых приложениях и позволяет проверять действия агента на реальной среде.

**SREGym-Lite** - облегчённый набор из **17 сценариев отказов** разной сложности, предназначенный для сравнительно простого воспроизведения. Для запуска используется Kubernetes; один из поддерживаемых способов - кластер **KIND** (Kubernetes in Docker). 

В рамках проекта SREGym-Lite используется как **испытательная среда для агента**. Агент получает симптомы инцидента, исследует доступные сведения о кластере, устанавливает причину отказа и, если предусмотрен этап исправления, пытается восстановить систему. SREGym поддерживает раздельные этапы диагностики (*diagnosis*) и устранения (*mitigation*).

## 2. Что понимается под сценарием

Под **сценарием отказа** понимается воспроизводимая неисправность, включающая:

1. **Исходное состояние** - сервисы работают корректно.
2. **Внесённую неисправность** - изменение конфигурации, нарушение доступа, ресурсное ограничение или программный дефект.
3. **Симптомы** - ошибки, задержки, недоступность, состояния Pod и события Kubernetes, которые может наблюдать агент.
4. **Задачу агента** - определить первопричину и, если разрешено, устранить её.
5. **Критерий проверки** - корректность диагноза и/или фактическое восстановление работоспособности.
